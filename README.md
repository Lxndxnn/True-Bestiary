# True Bestiary

True Bestiary improves the vanilla **Bestiary** by revealing enemy drops and their drop chances after just **one kill**. No more waiting for 25, 50, or more kills just to see what an enemy can drop.

## Features

- Reveals enemy **drop items** after just 1 kill.
- Reveals exact **drop chances** after just 1 kill.
- Uses Terraria's existing Bestiary drop information.
- Does **not** change actual enemy drop rates or loot tables.
- Does **not** change your Bestiary kill count.
- Works automatically with enemies already supported by the vanilla Bestiary.
- Includes a configuration option to enable or disable the 1-kill drop reveal.

## How It Works

1. Kill an enemy at least **once**.
2. Open the **Bestiary**.
3. Select the enemy you killed.
4. The enemy's **drops and exact drop chances** are immediately displayed.

## How To Download

1. Download the mod on Nexus Mods' website or the TerrariaModderVault.
2. Extract the files to your **`TerrariaModder/mods`** folder.
3. Load a new world (for a new Bestiary) or an existing one (to see drop chances that you haven't seen before).
4. Kill an enemy.
5. Check your Bestiary!

True Bestiary only changes what information the Bestiary displays. It does **not** modify enemy loot, drop rates, kill requirements for banners, or your actual gameplay drops.
